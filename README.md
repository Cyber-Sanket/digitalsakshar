# 🌐 Digital_Sakshar (डिजिटल साक्षर)

> **Digital Literacy Awareness Platform**

> *"Learn Digital. Practice Step-by-Step. Become Digital_Sakshar."* 🌐💻

**Digital_Sakshar** is an interactive, beginner-friendly digital literacy awareness web platform built to help students, beginners, parents, teachers, and senior citizens understand computers, perform basic computer operations, navigate the internet, access useful learning resources, test their knowledge, and earn an official printable certificate of digital literacy.

### 2. 💻 Computer Basics

This module introduces beginners to fundamental computer concepts and hardware components.

#### Topics Covered

- What is a Computer? (IPOS Cycle: Input, Process, Output, Storage)
- Parts of a Computer (Major hardware setup)
- Uses of Computers (Education, Banking, Healthcare, Communication, Daily Life)
- Input Devices vs Output Devices
- Hardware and Software Concepts
- Basic Computer Applications (Word processor, Web browser, Media player, Calculator, Paint, Notepad)
- Files and Folders Management

#### Computer Components (Anatomy Explorer)

Interactive component inspector with real-world analogies and speech synthesis:

- 🖥️ Monitor (Display Screen)
- 🧠 CPU (Central Processing Unit)
- ⌨️ Keyboard
- 🖱️ Mouse
- 📖 RAM (Random Access Memory)
- 💾 SSD/HDD (Permanent Storage)
- 🖨️ Printer (मुद्रक साधन)
- 🔊 Speakers & Headphones (ध्वनिक्षेपक)

---

### 3. 🖥️ Practical Computer Skills

The **Practical Computer Skills** module teaches users how to perform common computer tasks step-by-step.

The purpose of this module is:

> **"PC वर हे काम कसं करायचं?"**

Each practical lesson contains:

- 📌 Simple explanation (Bilingual: English + Marathi)
- 🧭 Direction / Where to find the feature
- 🪜 Step-by-step instructions
- 📊 Process Flowchart
- 🎥 YouTube demonstration video
- 💡 Beginner tip
- ✅ Try It Yourself hands-on interactive playground
- 🏆 Completion tracking

#### 9 Practical Lessons Included

1. 🎨 **How to Use Paint**: Opening Paint, selecting brush/pencil, choosing colors, drawing shapes, using the eraser, and saving drawings.
2. 📁 **How to Create a Folder**: Desktop right-click menu, New ➔ Folder, naming conventions, and organization.
3. 📝 **How to Create and Save a Text File**: Launching Notepad, typing notes, File ➔ Save As, and `.txt` format.
4. 📋 **How to Copy and Paste**: Ctrl+C, Ctrl+V, Cut (Ctrl+X), Undo (Ctrl+Z), and the Clipboard concept.
5. ✏️ **How to Rename a File or Folder**: Right-click rename, F2 shortcut key, and keeping file extensions intact.
6. 🗑️ **How to Delete a File**: Standard delete to Recycle Bin vs Permanent delete (`Shift + Delete`).
7. 🔄 **How to Restore a Deleted File**: Opening Recycle Bin, locating files, and right-click Restore.
8. 🖱️ **Mouse Basics & Actions**: Left Click, Double Click, Right Click context menus, Scroll wheel, and Drag & Drop.
9. ⌨️ **Keyboard Basics & Shortcuts**: Enter, Spacebar, Backspace, Delete, Shift, Ctrl, Alt, Tab, Esc, Arrow Keys, and top productivity shortcuts.

---

### 4. 🌐 Internet Basics

This module teaches beginners how to understand and use the internet safely.

- **Browser Anatomy Guide**: Address Bar, URL, HTTPS security lock, Back, Forward, Refresh, Tabs, and Bookmarks.
- **Search Engine Basics**: Search keywords, interpreting results, identifying suspicious links, and recognizing trusted portals (`.gov.in`).
- **Email Basics**: Recipient (To), Subject, Message body, Attachments, and Send, with pre-built practice templates (Leave Application, Course Inquiry, Feedback).
- **Download vs Upload**: Clear visual comparison and real-world everyday examples.
- **Wi-Fi Basics**: Wireless network names, passwords, signal strength, and safety rules for public Wi-Fi.

---

### 5. 📚 Learning Resources & Marathi Dictionary

- **Educational Video Tutorials**: High-quality lessons on computer fundamentals, files and folders management, internet basics, and keyboard shortcuts.
- **Study Notes & Cheat Sheets**: Printable quick-reference guide for essential PC shortcuts (Ctrl+C, Ctrl+V, Ctrl+Z, Ctrl+S, Ctrl+P, Alt+Tab, F2).
- **Digital Dictionary (A to Z)**: Searchable glossary of computer terminology with category filters and voice pronunciation.
- **Marathi ⇄ English Vocabulary**: Dedicated bilingual terminology table (e.g., Computer = संगणक, Keyboard = कळफलक, Mouse = माउस, Screen = पडदा, File = संचिका, Folder = धारिका, Internet = महाजाल, Download = उतरवणे, Printer = मुद्रक).

### 6. 🧠 Interactive Quiz

The platform includes 4 comprehensive quiz categories:

1. 💻 **Computer Basics** — 10 MCQs
2. 🖥️ **Practical Computer Skills** — 10 MCQs
3. 🌐 **Internet Basics** — 10 MCQs
4. 🏆 **Grand Digital_Sakshar Challenge** — 15 Mixed MCQs

#### Quiz Features

- Comprehensive explanations for every question
- Real-time progress bar and score calculation
- Final scorecard with achievement awards
- Complete question-by-question answer review

---

### 7. 📊 My Progress & Certificate

#### Progress Tracking

Progress is persisted using browser `localStorage` across all active modules:

- Computer Basics (25%)
- Practical Computer Skills (30%)
- Internet Basics (20%)
- Learning Resources (10%)
- Interactive Quizzes (15%)
- **Total Digital Literacy Index: 0–100%**

#### 🏆 8 Gamified Badges

- 🥉 **Beginner Learner**: Completed your first computer learning activity.
- 📁 **File Manager**: Completed folder and file practical lessons.
- 🎨 **Digital Artist**: Completed the Paint drawing practical lesson.
- 🌐 **Digital Explorer**: Explored Internet Basics and web browsing guides.
- 🖥️ **PC Skills Master**: Completed at least 5 Practical Computer Skills topics.
- 📚 **Learning Explorer**: Explored video tutorials, study notes, or Digital Dictionary.
- 🏆 **Quiz Champion**: Scored 80% or higher on any quiz.
- 🥇 **Certified Digital Sakshar**: Attained 75%+ overall digital literacy progress.

#### 📜 Printable Certificate Generator

After achieving a qualifying progress score, users can generate an official:

> **Certificate of Digital Literacy (डिजिटल साक्षरता प्रमाणपत्र)**

Includes candidate name personalization, unique Sakshar Verification ID, issue date, completion percentage, official-style seal, and print-ready CSS for paper or PDF export.

## 💻 How to Run Locally

### Option 1: Direct Browser Opening (Zero Setup)

Simply double-click `index.html` in your file explorer to open it in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Safari).

---

### Option 2: Local HTTP Server

#### Using Node.js

From the project folder:

```bash
cd D:\Project\Digital_Sakshar
node server.js
```

Then open:

```text
http://localhost:8080
```

#### Using Python

```bash
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```
